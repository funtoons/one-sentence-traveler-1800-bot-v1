## The sentence

> Picture one road joining every post office and library in the world, so a letter sent from any door can be read at any other before its ink is dry.

One sentence, 147 characters. It explains the modern internet to someone
arriving from 1800 using only things that person already knows — a road, a
post office, a library — with no word coined after their time and no list of
features: a single picture they can hold in their head.

## How it works

`main.py` writes the sentence to `/output/entry.txt`. It is deterministic
and offline: a fixed hand-written text, no randomness, no network, so every
run produces exactly the same bytes.

Run it with:

```sh
python3 main.py
```
